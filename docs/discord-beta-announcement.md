## Lacuna Shell beta is live 🎉

I’m excited to share **Lacuna Shell `v0.1.0-beta.2`** — a complete visual shell for Omarchy featuring:

- A custom bar, frame, and attached utility sidebar
- Media, audio, network, Bluetooth, weather, notifications, and system controls
- Theme-aware colors and wallpaper controls
- Configurable widgets, launchers, desktop clock, and ambience effects
- Transactional install, update, rollback, and uninstall support

Lacuna runs inside the existing Omarchy shell — no second shell process required.

### Install from the AUR

```bash
omarchy pkg aur add lacuna-shell
lacuna-shell
```

Choose **Full Lacuna install** for the intended setup. Preview everything first with:

```bash
lacuna-shell install --dry-run
```

> **This is a beta.** Expect some rough edges and changes before `0.1.0` stable. Feedback and bug reports are very welcome! When reporting an issue, please include the output of `lacuna-shell status` if possible.
